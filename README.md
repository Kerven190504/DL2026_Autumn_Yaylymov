# Атлас — географическая викторина

Игрок получает вопрос («Где находится Эйфелева башня?»), кликает по
карте мира, и система оценивает точность клика: чем ближе к
правильной точке, тем больше очков. Есть режим на 10 вопросов и
бесконечный режим, подсказки, таймер на вопрос и таблица лидеров.

Полное проектирование — в [`docs/design.md`](docs/design.md).
Рефлексия по использованию AI — в [`docs/AI_REFLECTION.md`](docs/AI_REFLECTION.md).

## Стек

- **Бэкенд:** Python 3.11+, FastAPI, SQLite (для таблицы лидеров)
- **Фронтенд:** React + Vite, Leaflet / react-leaflet, тайлы OpenStreetMap

## Запуск бэкенда

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

Бэкенд поднимется на `http://localhost:8000`. Интерактивная
документация API (Swagger) доступна на `http://localhost:8000/docs`.

## Тесты бэкенда

```bash
cd backend
pip install -r requirements-dev.txt
pytest -q
```

Покрыты: расчёт очков (`scoring.py`, параметризованные тесты вместо
похожих друг на друга копий) и весь игровой цикл API — старт партии,
подсказка, ответ, переход между вопросами, финиш и таблица лидеров.

## Запуск фронтенда

В отдельном терминале:

```bash
cd frontend
npm install
npm run dev
```

Фронтенд поднимется на `http://localhost:5173`. Запросы к API идут на
относительные пути (`/api/...`) — сам Vite-процесс проксирует их на
`localhost:8000` (см. `vite.config.js`, `server.proxy`). Браузеру
никогда не нужно знать порт бэкенда напрямую, поэтому это работает
одинаково на localhost, по LAN IP и через туннели (VPN/Tailscale и
т.п.), даже если наружу из такого туннеля проброшен только один порт
(5173). Чтобы указать реально другой бэкенд (отдельный прод-домен без
общего прокси), создайте `frontend/.env`:

```
VITE_API_URL=https://api.example.com
```

**Тестирование с телефона / другого устройства в той же сети:**
и `vite`, и `uvicorn` (см. выше — с флагом `--host 0.0.0.0`) уже
настроены слушать на всех интерфейсах. Узнайте LAN IP компьютера
(`ipconfig`/`ifconfig`) и откройте с телефона
`http://<IP-компьютера>:5173` — прокси сработает точно так же, как на
localhost. Если не открывается — скорее всего файрвол блокирует порт
5173 для входящих подключений в локальной сети (порт 8000 из браузера
уже не используется вообще, так что его блокировка ни на что не
влияет).

## Структура репозитория

```
docs/               design.md, AI_REFLECTION.md, /images
backend/            FastAPI-приложение
  app.py            эндпоинты API
  data.py           банк вопросов (локации)
  scoring.py        расчёт расстояния и очков
  db.py             SQLite: таблица лидеров
  models.py         Pydantic-схемы запросов/ответов
frontend/           React + Vite приложение
  src/App.jsx        состояние игры
  src/components/     UI-компоненты (карта, панели, экраны)
  src/api.js          обёртка над fetch к бэкенду
```

## Известные ограничения

- Игровая сессия хранится в памяти процесса бэкенда — при перезапуске
  сервера текущие партии сбрасываются (таблица лидеров при этом не
  теряется, она в SQLite).
- Для нескольких параллельных инстансов бэкенда потребовалось бы
  вынести состояние сессии во внешнее хранилище (Redis/БД) — для
  тестового задания это избыточно.
- 3D-глобус на стартовом экране (`react-globe.gl`, обёртка над
  three.js) заметно увеличивает размер фронтенд-бандла (~720 КБ
  gzip). Для чисто декоративного элемента это дорого; в реальном
  продакшене стоило бы либо лениво подгружать его через
  `React.lazy`/`import()`, либо вернуться к лёгкой 2D-карте.
- Предложенные игроками локации проходят только базовый фильтр на
  явный треш в названии/регионе (`moderation.py`) — не полноценную
  модерацию с очередью на проверку человеком. Прошедшая фильтр заявка
  сразу становится частью выбранной темы (столицы/достопримечательности/
  природные объекты) наравне с кураторскими локациями.
